# 2028RayanG数学练习题库

考研数学一静态练习网站。首版收录 2027 年张宇八套卷第 1 套和邂逅遗憾模拟卷第 1 套。张宇卷的选择题可在线作答，填空题和解答题分别有 A4 打印版。邂逅卷放在套卷精刷。后续整卷栏目限李林四套卷、张宇四套卷、邂逅四套卷及李艳芳三套卷，按年份标记。

- 点击「开始刷题」启动计时。选择题提交后立即判分。可暂停、继续、结束并保存或退出不保存。已保存的单次记录可逐条删除。
- 错题自动标星，其他题可手动标星。标星独立于做题记录，在「我的标星」中可按选择、填空、解答的顺序打印或保存为 PDF。
- 计时、作答和标星保存在当前浏览器。换设备、换站点地址或清除网站数据后，需要从该浏览器自己的记录重新开始。

## 本地运行与排版

可直接打开 `index.html`，也可在项目根目录运行 `python -m http.server 8767`。GitHub Pages 从 `main` 分支根目录发布。

题面采用 XeLaTeX 和 `exam-zh`。邂逅卷的编译入口是 `tex/xiehou/main.tex`。张宇卷在 `tex/zhang` 下用 `xelatex -halt-on-error fill.tex` 和 `xelatex -halt-on-error long.tex` 各编译两次生成打印版。选择题用 `choice-crops.tex` 生成逐题页，填空与解答可在编译时定义 `\QuestionCrops`。网页题面是编译结果的 300 DPI 渲染。邂逅解析保留整份原文件，张宇解析保留原文件第 7–18 页。

## 插画与字体

`assets/art/` 的四张插画由内置 ImageGen 按海贼王场景重新构图。提示词主题依次为梅利号告别、香克斯托付草帽、月下独立的三刀剑士、船员举臂告别薇薇。画面统一为冷蓝、银白与午夜海色，采用木刻与丝网印刷质感。

`assets/fonts/` 包含 Great Vibes、马善政毛笔楷书及 Noto Serif SC 的字体子集与许可。
